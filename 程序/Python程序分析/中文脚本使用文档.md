# 股票分析统一入口使用文档

本目录的股票分析工具已合并为**统一入口 `股票分析.py`**，用「功能」子命令 + 日期/代码等参数区分原先 10 个独立脚本的功能；另有 2 个教学脚本（股票模拟.py、随机漫步.py）保留原样（旧版 模拟持仓2.py 已于 2026-09 归档至 legacy/）。文档列出每个功能的**功能、运行方式、全部参数**。

## 总览

| 入口 | 功能 | 参数方式 |
|---|---|---|
| `股票分析.py 模拟持仓` | 区间买入持有模拟、买卖点分析 | 命令行参数 / 交互菜单 |
| `股票分析.py 波动分析` | 日/周/月线波动率分析 | 命令行参数 / 交互菜单 |
| `股票分析.py 红利再投` | 初始资金买入 + 分红再投,三策略对比 | 命令行参数 / 交互菜单 |
| `股票分析.py 红利再投增强版` | 从高点回撤 x% 一次性买入 y 万 + 红利再投 | 命令行参数 / 交互菜单 |
| `股票分析.py 大跌分批买入` | 当天大跌 x% 按最低价买入总仓位 y% 一笔 + 红利再投 | 命令行参数 / 交互菜单 |
| `股票分析.py 分红目标测算` | 某日买入多少资金,现在每年分红达标 | 命令行参数 / 交互菜单 |
| `股票分析.py 星期涨跌分析` | 星期几涨跌统计 | 命令行参数 / 交互菜单 |
| `股票分析.py 线性回归` | 线性回归拟合与收益率分析 | 命令行参数 / 交互菜单 |
| [股票模拟.py](#9-股票模拟py) | 随机事件驱动股价模拟(教学演示) | 无参数 |
| `股票分析.py 节日涨跌分析` | 节日前后涨跌统计 | 命令行参数 / 交互菜单 |
| [随机漫步.py](#11-随机漫步py) | 四种随机漫步对比(教学演示) | 无参数 |
| `股票分析.py 分红后涨跌统计` | 除息日后 N 个交易日下跌概率统计 | 命令行参数 / 交互菜单 |

## 统一入口用法

```bash
python3 股票分析.py                        # 无参数 -> 交互菜单(列出全部功能,逐项输入)
python3 股票分析.py --help                 # 列出全部功能与参数
python3 股票分析.py 红利再投 --help        # 查看某个功能的参数
python3 股票分析.py <功能> <参数...>       # 直接执行
```

- 无参数运行时显示交互菜单，选择功能后逐项提问（回车用默认值），与旧版交互式脚本体验一致。
- 子命令参数均有默认值；`--code` 默认 601857（模拟持仓 600519，行情类分析 000001）。
- 各功能实现位于 `analysis/tools/`，公共代码（参数解析、数据访问、涨跌幅/收益率统计、报告输出、图表）在 `analysis/`。

## 通用约定

- **运行位置**:必须在项目根目录(`程序/Python程序分析/`)下运行,入口内部会切换到脚本所在目录。
- **输出位置**:所有分析结果自动保存到 `results/<功能名>/<日期>/` 目录,包括:
  - `*.jpg` 图表(pyplot 绘制)
  - `<功能名>_<股票代码>_analysis_log.txt` 文字报告
- **图形窗口**:默认 `plt.show()` 弹窗;所有功能支持 `--no-chart` 关闭弹窗(**图片仍会保存**)。
- **数据依赖**:涉及行情的功能读本地 MySQL 数据库(`stock_daily_quote` 等);涉及分红的功能若库中无分红明细,会自动从东方财富拉取(`--sync` 可强制重拉)。
- **税率**:分红税率 0~1,默认 0(持股超过 1 年分红免税)。
- **买入单位**:A 股按 100 股一手整数倍买入,尾款留存现金。
- **前复权口径(成本价前复权)**:所有收益率计算均记录**每笔交易的日期/价格/数量**,并参考前复权 K 线,把每笔交易成本按**交易当日的前复权价**折算,再计算总体收益率:
  - 前复权成本 = Σ(每笔买入股数 × 当日前复权价),前复权成本均价 = 前复权成本 / 买入股数合计;
  - 前复权收益率 = (买入股数合计 × 最新前复权价) / 前复权成本 − 1(分红送转已隐含在复权价格中,现金资产另行列示);
  - 前复权数据缺失或覆盖不全时,该口径自动跳过并在报告"提示"中说明(需先同步前复权行情)。

## 1. 模拟持仓

**功能**:指定区间买入持有模拟,输出区间行情概览、买卖点分析、收益对比与图表。行情使用**前复权**价格(分红送转已还原);成本价按**除权除息逻辑**处理——每笔买入的实际成交价(不复权)在其持有窗口内逐次调整:现金分红→每股成本降低(并统计分红到账),送转股→股数增加、成本摊薄;报告列出每个策略的**实际成本均价**、**除权除息后成本均价**、**持有期分红送转**与**调整后收益率**(按调整后平均成本计算),以及逐笔交易明细(日期/价格/数量)。分红数据来自 MySQL,不可用时回退为前复权成本均价口径。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 600519 |
| `--start` | 起始日期 YYYY-MM-DD | 2024-01-01 |
| `--end` | 结束日期 YYYY-MM-DD | 今天 |
| `--capital` | 初始资金(元) | 100000 |
| `--no-chart` | 不显示图表 | 关闭 |

```bash
python3 股票分析.py 模拟持仓 --code 600519 --start 2024-01-01 --end 2025-01-01 --capital 200000
```

## 3. 红利再投

**功能**:期初按首日收盘价买入初始资金,此后每次分红到账"无脑买入"该股(红利再投),与「分红不投」「纯股价」三策略对比收益率、年化、最大回撤,输出分红明细与图表。报告另含**前复权口径**:每笔交易(建仓/红利再投)记录日期、价格、数量,成本按当日前复权价折算,给出前复权成本、成本均价与前复权收益率。策略对比同时列出**摊薄成本口径**:分红现金冲减买入成本后的**摊薄成本价**((Σ买入金额−Σ分红)÷期末股数,与券商 App 摊薄成本一致)与**调整后收益率**(期末收盘 vs 摊薄成本)。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 601857(中国石油) |
| `--start` | 起始日期 YYYY-MM-DD | 数据最早 |
| `--end` | 结束日期 YYYY-MM-DD | 数据最晚 |
| `--capital` | 初始资金(元) | 100000 |
| `--tax` | 分红税率 0~1 | 0 |
| `--sync` | 强制重新从东方财富拉取分红明细 | 关闭 |
| `--no-chart` | 不弹图形窗口(图片仍保存) | 关闭 |

```bash
python3 股票分析.py 红利再投 --code 601857 --start 2018-01-01 --capital 100000
```

## 5. 大跌分批买入

**功能**:每个交易日若**盘中最低价较前收盘跌幅 ≥ x%**(当天大跌),按当日**最低价**买入一笔,金额 = **总仓位 × y%**,每次触发买一笔直至现金用完,之后红利再投。对比:分批买入+再投 / 首触日全仓+再投 / 首触日全仓+不投。报告另含**前复权口径**收益率(每笔触发买入/红利再投按当日前复权价折算成本,含逐笔交易明细),以及**摊薄成本价/调整后收益率**(分红冲减成本口径,按实际成交最低价精确计算,同「红利再投」)。

> 口径:触发用盘中最低价(相当于挂"前收盘 −x%"限价单,盘中跌破即成交),成交价 = 当日最低价(不复权)。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 601857 |
| `--start` | 观察起点 YYYY-MM-DD | 数据最早 |
| `--end` | 观察终点 YYYY-MM-DD | 数据最晚 |
| `--dip` | 当日大跌阈值 % | 3 |
| `--position` | 总仓位(**万元**) | 100 |
| `--ratio` | 每笔买入占总仓位比例 % | 5 |
| `--tax` | 分红税率 0~1 | 0 |
| `--sync` | 强制重拉分红明细 | 关闭 |
| `--no-chart` | 不弹图形窗口 | 关闭 |

```bash
python3 股票分析.py 大跌分批买入 --code 601857 --position 100 --ratio 5 --dip 3
python3 股票分析.py 大跌分批买入 --code 600519 --position 50 --ratio 10 --dip 5 --start 2018-01-01
```

## 6. 分红目标测算

**功能**:给定**买入日期**和**目标年分红**(如 20 万/年),计算在买入日需要投入多少资金/股数,才能按红利再投策略在**现在**拿到目标年分红。参考分红口径可选:去年全年(`last_year`)或最近 12 个月(`trailing`)。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 601857 |
| `--buy-date` | 买入日期 YYYY-MM-DD(非交易日顺延到下一交易日) | 无 → 运行时交互输入 |
| `--target` | 目标每年分红到账金额(元) | 200000 |
| `--tax` | 分红税率 0~1 | 0 |
| `--reference` | 参考分红口径:`last_year`=去年全年 / `trailing`=最近12个月 | last_year |
| `--sync` | 强制重拉分红明细 | 关闭 |
| `--no-chart` | 不弹图形窗口 | 关闭 |

```bash
python3 股票分析.py 分红目标测算 --code 601857 --buy-date 2018-01-02 --target 200000
```

## 12. 分红后涨跌统计

**功能**:以分红**除息日**为锚点(当天收盘已是除息后价格,价格缺口已剔除),统计除息日后第 N 个交易日**下跌概率**(N 日累计涨跌幅为负的次数 ÷ 有效分红次数),同时给出各窗口平均涨跌幅、中位数、最大跌幅/涨幅,每笔分红明细,以及除息后逐日(1~N 日)平均累计涨跌幅曲线(事件研究口径)。除息日无行情时顺延到下一交易日。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 601857 |
| `--start` | 观察起点 YYYY-MM-DD | 数据最早 |
| `--end` | 观察终点 YYYY-MM-DD | 数据最晚 |
| `--days` | 统计窗口(逗号分隔的交易日天数) | 5,10,30 |
| `--sync` | 强制重拉分红明细 | 关闭 |
| `--no-chart` | 不弹图形窗口 | 关闭 |

```bash
python3 股票分析.py 分红后涨跌统计 --code 601857 --days 5,10,30
python3 股票分析.py 分红后涨跌统计 --code 601728 --days 5,10,30 --start 2021-08-20 --no-chart
```

## 附:常见问题

- **提示无行情数据**:先在网页版「数据导入」或接口 `POST /api/stocks/{code}/fetch` 同步行情。
- **分红数据缺失**:首次运行会从东方财富自动同步(需联网);加 `--sync` 可强制更新。
- **无参数进入交互菜单后在管道/无终端环境下**:交互输入遇 EOF 自动采用默认值或优雅退出。
- **matplotlib 中文字体**:已配置 SimHei/Arial Unicode MS/DejaVu Sans 回退,Linux 服务器无中文字体时图中中文可能显示为方块,不影响 txt 报告。
