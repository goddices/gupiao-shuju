# 中文 Python 脚本使用文档

本目录下的中文命名脚本均为 A 股分析工具。文档列出每个脚本的**功能、运行方式、全部参数**。

| 脚本 | 功能 | 参数方式 |
|---|---|---|
| [模拟持仓.py](#1-模拟持仓py) | 区间买入持有模拟、买卖点分析 | 命令行参数 / 交互输入 |

## 通用约定

- **运行位置**:必须在项目根目录(`程序/Python程序分析/`)下运行,脚本内部会切换到根目录。
- **输出位置**:所有分析结果自动保存到 `results/<脚本名>/<日期>/` 目录,包括:
  - `*.jpg` 图表(pyplot 绘制)
  - `<脚本名>_<股票代码>_analysis_log.txt` 文字报告
- **图形窗口**:默认 `plt.show()` 弹窗;带 `--no-chart` 参数的脚本可用它关闭弹窗(**图片仍会保存**)。
- **数据依赖**:涉及行情的脚本读本地 MySQL 数据库(`stock_daily_quote` 等);涉及分红的脚本若库中无分红明细,会自动从东方财富拉取(`--sync` 可强制重拉)。
- **税率**:分红税率 0~1,默认 0(持股超过 1 年分红免税)。
- **买入单位**:A 股按 100 股一手整数倍买入,尾款留存现金。
- **前复权口径(成本价前复权)**:所有收益率计算均记录**每笔交易的日期/价格/数量**,并参考前复权 K 线,把每笔交易成本按**交易当日的前复权价**折算,再计算总体收益率:
  - 前复权成本 = Σ(每笔买入股数 × 当日前复权价),前复权成本均价 = 前复权成本 / 买入股数合计;
  - 前复权收益率 = (买入股数合计 × 最新前复权价) / 前复权成本 − 1(分红送转已隐含在复权价格中,现金资产另行列示);
  - 前复权数据缺失或覆盖不全时,该口径自动跳过并在报告"提示"中说明(需先同步前复权行情)。

## 1. 模拟持仓.py

**功能**:指定区间买入持有模拟,输出区间行情概览、买卖点分析、收益对比与图表。行情使用**前复权**价格(分红送转已还原),报告列出每个策略的**前复权成本均价**与逐笔交易明细(日期/价格/数量)。

**参数**(命令行;若 `--code`/`--start`/`--end` 缺任一,则转为交互式提问):

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 交互默认 600519 |
| `--start` | 起始日期 YYYY-MM-DD | 交互默认 2024-01-01 |
| `--end` | 结束日期 YYYY-MM-DD | 交互默认今天 |
| `--capital` | 初始资金(元) | 100000 |
| `--no-chart` | 不显示图表 | 关闭 |

```bash
python3 模拟持仓.py --code 600519 --start 2024-01-01 --end 2025-01-01 --capital 200000
```

## 4. 红利再投.py

**功能**:期初按首日收盘价买入初始资金,此后每次分红到账"无脑买入"该股(红利再投),与「分红不投」「纯股价」三策略对比收益率、年化、最大回撤,输出分红明细与图表。报告另含**前复权口径**:每笔交易(建仓/红利再投)记录日期、价格、数量,成本按当日前复权价折算,给出前复权成本、成本均价与前复权收益率。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 601857(中国石油) |
| `--start` | 起始日期 YYYY-MM-DD | 数据最早 |
| `--end` | 结束日期 YYYY-MM-DD | 数据最晚 |
| `--capital` | 初始资金(元) | 100000 |
| `--tax` | 分红税率 0~1 | 0 |
| `--sync` | 强制重新从东方财富拉取分红明细 | 关闭 |
| `--no-chart` | 不弹图形窗口(图片仍保存) | 关闭 |

```bash
python3 红利再投.py --code 601857 --start 2018-01-01 --capital 100000
```

## 6. 大跌分批买入.py

**功能**:每个交易日若**盘中最低价较前收盘跌幅 ≥ x%**(当天大跌),按当日**最低价**买入一笔,金额 = **总仓位 × y%**,每次触发买一笔直至现金用完,之后红利再投。对比:分批买入+再投 / 首触日全仓+再投 / 首触日全仓+不投。报告另含**前复权口径**收益率(每笔触发买入/红利再投按当日前复权价折算成本,含逐笔交易明细)。

> 口径:触发用盘中最低价(相当于挂"前收盘 −x%"限价单,盘中跌破即成交),成交价 = 当日最低价(不复权)。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 601857 |
| `--start` | 观察起点 YYYY-MM-DD | 数据最早 |
| `--end` | 观察终点 YYYY-MM-DD | 数据最晚 |
| `--dip` | 当日大跌阈值 % | 3 |
| `--position` | 总仓位(**万元**) | 100 |
| `--ratio` | 每笔买入占总仓位比例 % | 5 |
| `--tax` | 分红税率 0~1 | 0 |
| `--sync` | 强制重拉分红明细 | 关闭 |
| `--no-chart` | 不弹图形窗口 | 关闭 |

```bash
python3 大跌分批买入.py --code 601857 --position 100 --ratio 5 --dip 3
python3 大跌分批买入.py --code 600519 --position 50 --ratio 10 --dip 5 --start 2018-01-01
```

## 7. 分红目标测算.py

**功能**:给定**买入日期**和**目标年分红**(如 20 万/年),计算在买入日需要投入多少资金/股数,才能按红利再投策略在**现在**拿到目标年分红。参考分红口径可选:去年全年(`last_year`)或最近 12 个月(`trailing`)。

**参数**:

| 参数 | 含义 | 默认 |
|---|---|---|
| `--code` | 股票代码 | 601857 |
| `--buy-date` | 买入日期 YYYY-MM-DD(非交易日顺延到下一交易日) | 无 → 运行时交互输入 |
| `--target` | 目标每年分红到账金额(元) | 200000 |
| `--tax` | 分红税率 0~1 | 0 |
| `--reference` | 参考分红口径:`last_year`=去年全年 / `trailing`=最近12个月 | last_year |
| `--sync` | 强制重拉分红明细 | 关闭 |
| `--no-chart` | 不弹图形窗口 | 关闭 |

```bash
python3 分红目标测算.py --code 601857 --buy-date 2018-01-02 --target 200000
```

## 附:常见问题

- **提示无行情数据**:先在网页版「数据导入」或接口 `POST /api/stocks/{code}/fetch` 同步行情。
- **分红数据缺失**:脚本会自动从东方财富同步(首次运行会联网);加 `--sync` 可强制更新。
- **交互式脚本 EOFError 提示**:交互脚本在管道/无终端环境下会自动采用默认值继续运行。
- **matplotlib 中文字体**:脚本已配置 SimHei/Arial Unicode MS/DejaVu Sans 回退,Linux 服务器无中文字体时图中中文可能显示为方块,不影响 txt 报告。
