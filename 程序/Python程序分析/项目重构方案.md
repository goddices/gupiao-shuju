## P0 红利再投家族工具公共化（已完成，2026-09-07）

**前置修复**：`红利再投增强版.py`、`大跌分批买入.py` 使用 Python 3.12+ 嵌套同引号 f-string，
在项目运行时 3.10 下 SyntaxError，且 `build_parser()` import 全部工具 → **统一入口整体瘫痪**。
已改为输出完全相同的 `'{:.2f}%'.format(...)` 写法（旧脚本字节码证实原格式即 `:.2f`）。

**重构内容**：新建 `analysis/tools/_reinvest_common.py`（包内私有，约 200 行），收敛三工具
逐字相同的：三策略对比 rows 构建（×3）、前复权口径节（×3）、分红明细+提示节（×3）、
累计分红行（×3）、对比图骨架（×3）、run() 骨架（×3）、公共问项（×3）。
三文件 679 行 → 约 470 行；「年化」格式统一为 `:.2f`。

**验证**：601857 全量重跑，去时间戳逐字节 diff——增强版/大跌分批 **0 差异**；
红利再投仅 `年化: -6.6%` → `-6.60%` 一处（迁移时 `round()` 写法与旧脚本 `:.2f` 的偏差，按方案统一）；600036 抽验通过；`--help` 全量 import 通过。
详见《红利再投系列工具-重构方案.md》。
